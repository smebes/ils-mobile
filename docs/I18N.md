# Çoklu dil (i18n) — SprachApp

**Ürün:** mobil (iOS / Android). Web yalnızca geliştirme testi.

## İlke

| Katman | Dil |
|--------|-----|
| **Uygulama arayüzü** (menü, buton, onboarding, hata) | Kullanıcının seçtiği dil (`tr` / `en` / `fr`) |
| **Öğrenme içeriği** (kelime, diyalog, egzersiz yönergesi) | Her zaman **Almanca (de-DE)** |

Fransız bir kullanıcı menüyü Fransızca görür; ders içinde yine `Guten Tag`, `heißen` vb. görür.

## Teknik

- Flutter gen-l10n: `mobile/lib/l10n/app_*.arb`
- Destek: **en** (şablon), **tr**, **fr**
- Tercih: `ProgressStore.uiLocaleCode` → Profil → “Uygulama dili”
- İlk açılış: cihaz dili tr/fr/en ise o; değilse **en**

## Yeni dil eklemek

1. `lib/l10n/app_xx.arb` oluştur (tüm anahtarlar)
2. `flutter gen-l10n`
3. Profil dil listesine ekle
4. İçerik çevirileri (kelime TR/FR) ayrı pipeline — `uebersetzung_*` alanları

## Bilinen boşluk

Flashcard çeviri metni şu an içerikte çoğunlukla `uebersetzung_tr`. UI dili FR olsa bile çeviri TR kalabilir — içerik JSON’a `uebersetzung_fr` / `uebersetzung_en` eklenmeli.
